# Adgreens landscape

Premium multi-page website for Adgreens landscape — garden design, landscaping and outdoor care in Nairobi, Kenya.

## Pages

- `/` Home
- `/about` About
- `/services` Services
- `/projects` Projects
- `/process` Process
- `/contact` Contact

## Run locally

```bash
cd D:\serene-swimming-pools
npm install
npm run dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000).

## Site content

Edit these files only — the layout stays the same:

- `src/data/site.ts` — phone, WhatsApp, email, address, navigation
- `src/data/content.ts` — projects, testimonials, services copy
- `src/data/images.ts` — photography URLs and alt text
